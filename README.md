# Rock Paper Scissors

This application lets users play a round of rock paper scissors against a computer opponent and keeps score.

## Features

- Interactive player choice buttons
- Randomized computer opponent logic
- Live score tracking scoreboard
- Round winner determination

## How it works

The application listens for click events on the choice buttons and generates a random choice for the computer. It then compares both choices to determine the winner and updates the score counters and display boxes accordingly.

## Run

Open `index.html` in a browser. No install or build step.

## Files

- `index.html`: Main markup structure for the app
- `style.css`: Design variables and layout rules
- `script.js`: Game logic and score management
